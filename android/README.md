# Job Agent for Android

A small app that opens the deployed demo full screen (pink briefcase icon, "Job Agent").
PDF CVs from the download buttons are saved to the phone's Downloads folder; links to job sites
open in the normal browser.

**Get the APK:** GitHub → this repo → Releases → `android-latest` → `JobAgent.apk` (open it on the phone).

**Build:** GitHub Actions builds it on every change in `android/`. To point it at another link:
Actions → Android APK → Run workflow → paste the link. No Android Studio needed.
