# 王雨晨（虚构候选人）项目资料

## 电商客服知识库问答（RAG）
- 为电商客服搭建基于检索增强生成的问答系统，知识库包含 1.2 万篇商品说明、售后政策与常见问题。
- 文档按标题切分后再按 512 字切块，向量模型使用 bge-large-zh，向量库选用 Milvus，支持按店铺过滤。
- 召回后用 bge-reranker-base 交叉编码器重排，取前 4 段拼入提示词，回答必须附上原文链接。
- 构建 300 条带标准答案的测试问题，召回率@5 从 71% 提升到 86%，答案正确率人工抽检 92%。
- 上线后客服转人工率下降 18%，平均响应时间从 45 秒降到 6 秒。

## 小程序订单后端
- 使用 Go 和 Gin 框架开发微信小程序订单服务，MySQL 存储订单，Redis 缓存库存，接口压测 QPS 达到 3200。
- 用消息队列 RocketMQ 处理下单与库存扣减，保证最终一致性。

## 医药知识图谱问答（课程项目）
- 从药品说明书中抽取药品、适应症、禁忌和相互作用四类实体与关系，构建约 3 万个节点的知识图谱，存储在 Neo4j 中。
- 用户问题先做实体链接，再把自然语言问题转换为 Cypher 查询；复杂问题拆成多跳查询。
- 与纯向量检索对比：在"两种药能否同时服用"这类多跳问题上，图谱查询的准确率高出 23 个百分点。
- 局限：说明书格式不统一，实体抽取的召回率只有 81%，部分关系需要人工补充。

## 实习：搜索中台数据开发（2023 年夏）
- 维护商品搜索的离线日志表，用 Hive SQL 统计查询词的点击率与无结果率，每天生成报表。
- 编写查询词纠错的词典更新脚本，无结果搜索占比从 4.1% 降到 2.7%。
