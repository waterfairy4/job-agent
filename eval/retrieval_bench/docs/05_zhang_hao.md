# 张浩（虚构候选人）项目资料

## 医疗问答模型后训练
- 在 Qwen2-7B 上做指令微调（SFT），训练数据为 8 万条脱敏医患对话，经过去重和质量打分筛选。
- 用 LoRA（rank 16、alpha 32）训练，DeepSpeed ZeRO-2，8 张 A100 训练 14 小时。
- 构建 2 万对偏好数据，由医生在两个回答中选择更安全、更准确的一个，再用 DPO 做偏好对齐。
- 安全评测：拒答率在高风险问题上从 41% 提升到 87%，普通问题的过度拒答控制在 3% 以内。

## 数学推理强化学习
- 复现 GRPO：以答案是否正确作为可验证奖励，在 GSM8K 训练集上训练 Qwen2.5-1.5B，每题采样 8 个回答计算组内相对优势。
- 测试集准确率从 62% 提升到 71%；观察到回答长度随训练增长，加入长度惩罚后趋于稳定。

## 指令数据合成
- 参考 Self-Instruct 和 Evol-Instruct，用强模型从 300 条人工种子指令扩展出 5 万条指令数据，覆盖写作、推理与代码。
- 质量过滤：用奖励模型打分、去掉与种子过于相似的样本、用规则剔除格式错误；最终保留 2.3 万条。
- 用合成数据做 SFT 后，在 MT-Bench 上从 6.1 提升到 6.8；与只用人工数据训练相比，代码类任务提升最明显。

## 奖励模型训练
- 基于 Bradley–Terry 损失训练 7B 奖励模型，在留出偏好集上的准确率 72%；分析发现奖励模型偏爱更长的回答，加入长度归一化后偏差减小。
