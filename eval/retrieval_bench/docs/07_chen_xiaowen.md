# 陈晓雯（虚构候选人）项目资料

## 短视频推荐系统
- 召回层使用双塔模型（用户塔与视频塔），离线 Recall@100 提升 6.4%；粗排使用轻量 MLP。
- 精排采用 DIN 模型建模用户历史行为与候选视频的注意力关系，线上 AUC 提升 1.2%。
- 特征工程：用户活跃时段、完播率、作者关注关系等 140 个特征，用 Spark 每日离线计算。
- 两周线上 A/B 实验：人均观看时长 +3.8%，显著性检验 p < 0.01。

## 用户增长分析
- 用 SQL 和 Python 搭建新用户留存看板，按渠道拆分次日与 7 日留存。
- 通过漏斗分析发现注册流程第三步流失最严重，改版后注册转化率提升 9%。

## 搜索广告点击率预估
- 使用 DeepFM 模型预估广告点击率，处理高维稀疏的类别特征（用户 ID、广告 ID、查询词），线上 CTR 提升 2.1%。
- 负采样后对预估值做校准，保证出价系统使用的点击率不被高估。
- 实时特征通过 Flink 计算最近一小时的点击与曝光，延迟控制在 30 秒内。

## 课程项目：电影评分预测
- 在 MovieLens 数据集上比较矩阵分解、协同过滤和 LightGCN，RMSE 最低为 0.861。

## 技能
- Python、SQL、Spark、TensorFlow；推荐算法、A/B 实验设计、数据分析。
