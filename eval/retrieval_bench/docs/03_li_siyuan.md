# 李思远（虚构候选人）项目资料

## 中文数学推理评测集 C-MathEval
- 设计并构建中文数学推理评测集，共 500 道题，覆盖小学应用题、初中代数与高中概率，按难度分三级。
- 答案判定采用两步：先用正则抽取最终数值，抽取失败再交给 LLM 判分；判分结果与两位人工标注者的一致性 Cohen's κ 为 0.81。
- 对 9 个开源与闭源模型评测，发现链式思维提示在高难度题上平均提升 11 个百分点，但在简单题上几乎无增益。
- 分析数据污染：用 13-gram 重叠检测训练语料，剔除 37 道可能泄露的题目。

## 代码生成评测
- 在 HumanEval 与自建的 120 道 Python 题上评测代码模型，指标为 pass@1 与 pass@10，执行在隔离的 Docker 沙箱中进行。
- 统计每个模型的失败类型：语法错误、超时、逻辑错误，并给出错误样例分析报告。

## 机器翻译质量评测
- 比较 BLEU、chrF 与 COMET 三种自动指标和人工评分的相关性，数据为 6 个语言方向、每个方向 400 句。
- 发现 COMET 与人工直接评估（DA）的 Kendall τ 最高；BLEU 在中英方向上与人工排名经常相反。
- 组织 5 名标注者做 MQM 错误标注，统计术语错误、漏译和语序错误的分布。

## 评测平台工程
- 把评测脚本封装成命令行工具：统一的数据格式、断点续跑、结果缓存和自动生成 Markdown 报告。
- 每次模型更新后在 CI 中运行小型回归评测，分数下降超过阈值时提醒研究员。

## 技能
- Python、PyTorch；vLLM 批量推理；统计检验（bootstrap 置信区间）；LaTeX。
