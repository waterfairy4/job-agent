# 周敏（虚构候选人）项目资料

## 工业零件表面缺陷检测
- 基于 YOLOv8 训练缺陷检测模型，识别划痕、凹坑、裂纹三类缺陷，数据集 6,500 张产线图片。
- 针对样本不均衡，使用 Mosaic、随机旋转和缺陷贴图等数据增强，小目标裂纹的召回率提升 15%。
- 测试集 mAP@0.5 达到 0.87；误检主要来自反光区域，加入偏振光拍摄后明显减少。
- 用 TensorRT 量化为 FP16，部署到 Jetson Orin 边缘设备，单张推理 18 毫秒，满足产线节拍。

## 图像标注平台
- 用 Vue 和 Flask 开发内部标注工具，支持框选、多边形标注和多人审核，标注效率提升约 40%。

## 票据 OCR 识别系统
- 识别增值税发票上的发票号码、金额和开票日期，检测用 DBNet，识别用 CRNN，并按版式规则做字段对齐。
- 针对盖章遮挡和低分辨率扫描，合成了 2 万张带印章噪声的训练图片，字段级准确率从 88% 提升到 95%。
- 把识别结果与金额校验规则结合（税额 = 金额 × 税率），自动标记可疑票据交给人工复核。

## 课程项目：图像分类模型压缩
- 对 ResNet-50 做通道剪枝和知识蒸馏，模型大小减少 70%，ImageNet 子集上准确率只下降 1.4 个百分点。

## 技能
- Python、C++；PyTorch、OpenCV、TensorRT；Linux 边缘部署。
